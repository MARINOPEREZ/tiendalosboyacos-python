────────────────────────────────────────────────────────────────────
  REQUISITOS DEL SISTEMA
────────────────────────────────────────────────────────────────────

  - Python          3.13+
  - XAMPP           8.x (Apache + MariaDB)
  - pip             (incluido con Python)
  - Navegador       Chrome / Edge (recomendado)
  - Sistema         Windows 10/11

────────────────────────────────────────────────────────────────────
  DEPENDENCIAS PYTHON (requirements.txt)
────────────────────────────────────────────────────────────────────

  flask               3.x
  mysql-connector-python
  werkzeug
  reportlab
  pypdf

  Instalar con:
    pip install -r requirements.txt

────────────────────────────────────────────────────────────────────
  INSTALACIÓN PASO A PASO
────────────────────────────────────────────────────────────────────

  1. Iniciar XAMPP → Apache + MySQL (MariaDB)

  2. Crear la base de datos en phpMyAdmin:
     - Nombre: tiendalosboyacos
     - Cotejamiento: utf8mb4_unicode_ci
     - Importar: setup.sql (si existe) o ejecutar las migraciones

  3. Ejecutar seed inicial:
       cd seeds
       python seed_roles.py

  4. Iniciar la aplicación:
       cd C:\xampp\htdocs\PROYECTOS\tiendalosboyacos-python
       python app.py

  5. Abrir en el navegador:
       http://localhost:5000

────────────────────────────────────────────────────────────────────
  ARQUITECTURA — MVC (Modelo-Vista-Controlador)
────────────────────────────────────────────────────────────────────

  CLIENTE (Navegador)
      ↕ HTTP
  VISTA (templates/*.html — Jinja2 + JS)
      ↕
  RUTAS (app.py — Flask)
      ↕
  CONTROLADOR (src/controllers/ — lógica de negocio)
      ↕
  MODELO (src/models/ — acceso a BD)
      ↕
  BASE DE DATOS (MariaDB — tiendalosboyacos)

────────────────────────────────────────────────────────────────────
  BASE DE DATOS — TABLAS
────────────────────────────────────────────────────────────────────

  Tabla               Descripción
  ─────────────────── ──────────────────────────────────────────────
  rol                 Roles del sistema (Admin, Cliente, Domiciliario)
  rolxusuario         Relación N:M entre ROL y USUARIO
  usuario             Usuarios registrados (clientes, admins, domiciliarios)
  cuenta              Cuenta bancaria/perfil vinculada a cada usuario
  categoria           Categorías de productos (Frutas, Carnes, etc.)
  categoriaxproducto  Relación N:M entre CATEGORIA y PRODUCTO
  producto            Catálogo de productos de la tienda
  inventario          Registro histórico de stock por producto
  venta               Cabecera de cada venta realizada
  detalle             Líneas de detalle de cada venta (productos comprados)
  qr_pago             Códigos QR de pago configurados por el admin
